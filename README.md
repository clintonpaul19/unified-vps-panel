# Unified VPS Panel

All-in-one VPS management panel for Hysteria 2, Xray, SSH, SSH WebSocket/WSS, BadVPN and unified CLI/web management.

## Installation

### Fresh VPS — recommended

Run as root:

```bash
curl -fsSL https://raw.githubusercontent.com/clintonpaul19/unified-vps-panel/main/install.sh | bash
```

Or with wget:

```bash
wget -qO- https://raw.githubusercontent.com/clintonpaul19/unified-vps-panel/main/install.sh | bash
```

After installation:

```bash
vps-status
menu
```

View the generated panel credentials:

```bash
cat /etc/unified-vps/panel.env
```

The web panel listens on TCP **2087**.

## Xray port layout

The installer uses the requested public Xray ports:

| Protocol | Public port | Transport |
|---|---:|---|
| VLESS | TCP 80 | WebSocket, path `/vless` |
| VMess | TCP 443 | WebSocket + TLS, path `/vmess` |
| Trojan | TCP 443 | TLS |

VMess and Trojan share TCP 443 through Xray fallback/path routing. The VMess backend listens only on `127.0.0.1:10086`; port 10086 is not exposed publicly.

VLESS on port 80 uses WebSocket without TLS. This is intentional because you requested VLESS on port 80. For TLS-protected VLESS, use a TLS-enabled VLESS deployment on 443 instead.

Xray documents fallback as a mechanism for sharing a common port and routing by HTTP path, and both VLESS and Trojan support fallbacks. citeturn1search3turn1search4

### Client settings

VLESS:

```text
Address: SERVER_IP
Port: 80
Network: WebSocket
Path: /vless
TLS: Off
UUID: generated by the panel
```

VMess:

```text
Address: SERVER_IP
Port: 443
Network: WebSocket
Path: /vmess
TLS: On
UUID: generated by the panel
```

Trojan:

```text
Address: SERVER_IP
Port: 443
Network: TCP
TLS: On
Password: generated by the panel
```

The installer generates a self-signed certificate for Xray at:

```text
/etc/unified-vps/xray.crt
/etc/unified-vps/xray.key
```

For normal TLS certificate validation, replace these with a certificate for your domain and keep the same paths, then run:

```bash
xray -test -config /usr/local/etc/xray/config.json
systemctl restart xray
```

Because the default certificate is self-signed, clients using VMess/Trojan must either trust the certificate or use the client's insecure/allow-insecure option until you install a trusted certificate.

## Validation

Test the Xray configuration:

```bash
xray -test -config /usr/local/etc/xray/config.json
```

Check listeners:

```bash
ss -lntp | grep -E ':(80|443|10085|10086)\\b'
```

Expected:

- TCP 80: public VLESS listener.
- TCP 443: public Trojan listener.
- TCP 10086: loopback-only VMess backend.
- TCP 10085: loopback-only Xray API.

Xray's statistics system is also enabled for user uplink/downlink/online statistics. citeturn2search0turn2search3

## Default ports

|---|---:|
| SSH | TCP 22 |
| VLESS | TCP 80 |
| VMess + TLS | TCP 443 |
| Trojan + TLS | TCP 443 |
| Hysteria | UDP 53 |
| Unified Panel | TCP 2087 |
| BadVPN UDPGW | UDP 7100–7300 |

## Important

The project is still under development. Test it on a fresh VPS before production use.

Do not expose or commit `/etc/unified-vps/panel.env`; it contains the generated panel administrator password.
